# Daily Planner

Click the panel icon beside **Targets**, or press **Ctrl+Alt+P** (**Cmd+Option+P** on macOS). The same shortcut closes the Planner from the editor. Pick a day in Calendar or use the date and arrows above the timeline. Pin the Planner date to navigate independently of the Calendar. Unpin to follow the Calendar again. Set working hours in **☰ → Settings**. Drag the left divider to resize the Planner, or focus the divider and use the arrow keys. Closing the Planner returns the space to the ordinary editor sidebar.

Click an empty slot or focus the timeline and press Enter to plan a Note, Todo or meeting. Dragging from the Outline allocates a session. The first session gives an unscheduled item a scheduled date. Dragging a Todo from another Calendar day also moves that scheduled date. For an ordinary Todo, the checkbox completes the session. For a recurring Todo, it also updates that occurrence in the Calendar and Outline. Double-click opens the document. Drag the body to move a block or the lower edge to change its duration. Right-click for date changes, removal and recurrence options. Choose **+** beside the time label to expand just that 15-minute interval into rows of up to three blocks. The gutter ticks track quarter hours, and later times move down to make room. Choose **−** to collapse it.

For a recurring Todo, choose **Repeat with Todo** on a session to repeat its time allocation. Individual changes are saved against the original occurrence. Changing future sessions adds a dated revision. Use Undo to reverse a planning change, including status or archive changes that removed future sessions.

Create meetings from the same slot menu. Choose **All day** for date-only events. The end date of a multi-day all-day event is exclusive. Double-click any occurrence to write in the shared meeting document. Right-click to edit scheduling, associate a parent, cancel an occurrence, end a series, or delete the meeting and document. Search the Outline for the meeting title, document text or parent. Ended series can be restarted from their search results.

**☰ → Import Outlook Calendar…** opens the offline import workflow. Pick the .ics file and review the dates it contains. The preview matches imported series by Outlook UID and calendar identity. Expand a series to inspect changes. **Reimport Outlook Calendar…** rereads the previous file on this computer. **Review duplicate Outlook meetings…** can consolidate verified identical copies after approval. Conflicting documents and unverified matches remain available for review.

Imported occurrences are limited to dates supported by the export. A clipped Outlook count can grow on the next import. Missing entries and subsequent Outlook cancellations leave previously imported occurrences in place. An unbounded rule without a verified end imports only explicit dates and produces a warning. Very high-frequency series with multiple starts per day are outside the Planner's supported recurrence model. Review warnings before confirming. Reimport preserves the shared document and parent.

## Storage and recovery

Planner data uses the same local SQLite transaction, autosave, Undo and revision history as the rest of the library. The first save containing Planner records upgrades SQLite to version 3. Older app versions reject that SQLite file. Install the Planner-capable version on both computers before using handoff. A handoff, rolling backup or complete JSON recovery export includes Planner records and referenced meeting images. Normal close publishes the committed Planner data for automatic handoff.
